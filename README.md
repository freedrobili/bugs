# Охота на баги

Учебный сайт выдуманной пиццерии «Корж» для офлайн мастер-класса по тестированию для школьников. Дети по очереди подходят к одному компьютеру, вводят имя, ищут баги на сайте и «ловят» их за баллы.

| Уровень | Страница | Что внутри |
|---|---|---|
| 1 | `index.html` | 19 багов: опечатки, вёрстка, убегающая кнопка, простая логика корзины и формы |
| 2 | `level2.html` | 16 багов в расчётах: округления, граничные значения, скидки, бонусы, время |

## Запуск

```bash
python3 server.py
```

Затем откройте в браузере http://localhost:5173. Нужен Python 3.8 или новее, дополнительные пакеты и интернет не нужны.

## Статистика

Каждое событие обоих уровней записывается в `stats/statistics.csv`: имя участника, уровень, какой баг найден и через сколько времени от старта. Файл открывается в Excel.
