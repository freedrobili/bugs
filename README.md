# Охота на баги

Учебный сайт выдуманной пиццерии «Корж» для офлайн мастер-класса по тестированию для школьников. Дети по очереди подходят к одному компьютеру, вводят имя, ищут баги на сайте и «ловят» их за баллы.

| Уровень | Страница | Что внутри |
|---|---|---|
| 1 | `index.html` | 21 баг: опечатки, вёрстка, убегающая кнопка, простая логика корзины и формы |
| 2 | `level2.html` | 18 багов, в основном в расчётах: округления, граничные значения, скидки, бонусы, время |
| 3 | `level3.html` | 17 простых и смешных багов парка аттракционов: возраст, полоски загрузки, QR-коды, счётчики |
| 4 | `level4.html` | 12 багов мобильного приложения: ищутся в режиме разработчика браузера на разных телефонах |

На уровнях 1–3 есть тёмная тема и кнопки, ломающие вёрстку. Счёт на каждом уровне свой. Переход между уровнями — меню «Уровень 1 2 3 4» на нижней панели.

## Запуск

```bash
python3 server.py
```

Затем откройте в браузере http://localhost:5173 (лучше в Google Chrome: для уровня 4 нужен его режим разработчика). Нужен Python 3.8 или новее, дополнительные пакеты и интернет не нужны.

## Статистика

Каждое событие всех уровней записывается в `stats/statistics.csv`: имя участника, уровень, какой баг найден и через сколько времени от старта. Файл открывается в Excel.
